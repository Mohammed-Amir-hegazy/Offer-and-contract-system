# Ebtikar — نظام عروض الأسعار والعقود

منصة ويب (عربي) من ابتكار لشركات التطوير العقاري: عروض أسعار بالأقساط، صياغة عقود تلقائياً، وتوقيع إلكتروني من الطرفين.

## مالك النظام والعملاء

- **مالك النظام (ابتكار):** أول حساب أدمن (`ADMIN_USERNAME` / `ADMIN_PASSWORD`). بيدخل على **لوحة المالك**: يضيف عملاء (شركات تطوير) ويعمل لكل عميل حساب أدمن، يوقف أو يفعّل أي حساب، ويقدر يدخل على أي حساب عميل ويديره بصلاحيات الأدمن كاملة.
- **كل عميل منفصل تماماً:** مستخدمينه، شركاته وهوياتها، وحداته (نفس أكواد الوحدات ممكن تتكرر بين العملاء)، أسعاره، إعداداته، صيغة عقده، وعروضه وعقوده بترقيم خاص بيه. محدش من عميل يقدر يشوف بيانات عميل تاني.
- **أول عميل:** عمر نجم جروب، بوحدات كمباوند شرفات وصيغة عقده. عند الترقية من النسخة القديمة، كل البيانات الموجودة بتتحول تلقائياً لحساب العميل ده، وأول أدمن بيبقى مالك النظام.

## العقد وعرض السعر

- العقد بنفس تقسيم صفحات العقد الأصلي (30 صفحة) وألوانه، وعلى كل صفحة لوجو الشركة ورقم الصفحة، و**توقيع الطرفين أسفل كل صفحة** (ممكن إلغاؤه من الإعدادات). أي صيغة عقد تقدر تقسمها صفحات بعلامة فاصل الصفحة.
- عرض السعر بيتطبع في **صفحة واحدة**؛ جدول الأقساط بيتقسم أعمدة جنب بعض حسب عدد الأقساط (لحد 120 قسط).
- **تصدير:** العقد إلى **Word** (من اليمين لليسار، لوجو ورقم الصفحة في الهيدر، توقيع الطرفين في فوتر كل صفحة، والتوقيعات والختم والمخططات)، وعرض السعر إلى **Excel** (بمعادلات الإجمالي، ومتظبط للطباعة في صفحة).

## الهوية

- **واجهة السيستم** بهوية ابتكار: اللوجو (`public/img/ebtikar-logo*.png`)، الألوان `#06044B` و `#5146E1` و `#62E98A`، وخط DIN Next LT Arabic (`public/fonts`).
- **المطبوعات** (عروض الأسعار، العقود، صفحة التوقيع) بهوية الشركة المالكة للوحدة. يدعم السيستم أي عدد من الشركات، ولكل شركة لوجو ولون أساسي وثانوي وخط (من قائمة خطوط عربية أو برفع ملف خط الشركة) وبياناتها وموقّعها وصيغة عقد خاصة اختيارياً.
- كل عرض وعقد يحتفظ بهوية الشركة وقت إصداره، فتعديل الهوية لاحقاً لا يغيّر المستندات السابقة.

## التشغيل محلياً

يتطلب Node.js 22.

```bash
npm install
npm start          # http://localhost:3000
npm test           # اختبارات حساب الأقساط والتفقيط
```

محلياً البيانات بتتحفظ في ملف `data/app.db` والصور في `data/uploads` من غير أي خدمات خارجية.
أول تشغيل ينشئ حساب أدمن: **admin / admin123** (أو من `ADMIN_USERNAME` / `ADMIN_PASSWORD`)، ويُطلب تغيير كلمة المرور عند أول دخول،
ويُحمّل الـ 147 وحدة من `data/units.csv`.

## النشر على Vercel

Vercel مش بيحتفظ بأي ملفات، فقاعدة البيانات على **Turso** والصور والخطوط على **Vercel Blob**:

1. في مشروع Vercel: **Storage → Create Database → Turso** واربطها بالمشروع (بتضيف `TURSO_DATABASE_URL` و `TURSO_AUTH_TOKEN` تلقائياً).
2. **Storage → Create → Blob** واربطه بالمشروع (بيضيف `BLOB_READ_WRITE_TOKEN` تلقائياً).
3. **Settings → Environment Variables**: أضف `ADMIN_PASSWORD` (كلمة سر قوية للأدمن الأول) و `SESSION_SECRET` (نص عشوائي طويل).
4. **Deployments → Redeploy**.

الجداول والوحدات وحساب الأدمن بيتعملوا تلقائياً مع أول زيارة. لو حاجة من دول ناقصة، السيستم بيعرض رسالة بالمطلوب بدل الخطأ.
الإعدادات في `vercel.json` (لازم Framework Preset يكون Other). أقصى حجم لأي ملف مرفوع 4 ميجا.

| متغير بيئة | الوظيفة |
|---|---|
| `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` | قاعدة البيانات على Turso (لو مش موجودين: ملف محلي) |
| `BLOB_READ_WRITE_TOKEN` | تخزين الصور والخطوط على Vercel Blob (لو مش موجود: مجلد محلي) |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | بيانات الأدمن الأول |
| `SESSION_SECRET` | مفتاح تأمين الجلسات |
| `PUBLIC_URL` | الرابط العام للسيستم في روابط التوقيع (اختياري) |
| `APP_TZ` | المنطقة الزمنية للتواريخ وأوقات التوقيع (افتراضي `Africa/Cairo`) |
| `PORT`, `DATA_DIR` | للتشغيل المحلي |

## سيناريو المستخدم

1. **الدخول** بحساب ينشئه الأدمن فقط (لا يوجد تسجيل ذاتي). الأدمن يقدر يوقف أي حساب فوراً.
2. **الاختيار**: عرض سعر أو عقد.
3. **عرض السعر**: اسم العميل + كود الوحدة → تظهر فوراً العمارة والدور والنموذج والمساحة والحديقة وعدد الغرف والسعر وصورة النموذج. لو الوحدة **مباعة** تظهر رسالة ولا يمكن الإصدار.
4. يحدد الموظف **الخصم %، المقدم %، مدة التقسيط بالسنوات، والسداد كل كام شهر** في حدود صلاحياته، والأقساط تتحسب لحظياً.
5. **العقد**: من عرض سعر (زر "تحويل إلى عقد") أو مباشرة بكود الوحدة + بيانات العميل → يُصاغ العقد بنفس الحسابات.
6. **الطباعة** أو **إرسال روابط التوقيع**: رابط للعميل ورابط لصاحب الشركة (مع زر واتساب). كل طرف يوقع مرة واحدة، والتوقيع يظهر في كل أماكن التوقيع المحددة له في العقد. العميل يُدخل رقمه القومي للتحقق.

## قواعد الحساب

- الخصم نسبة من سعر الوحدة.
- المقدم نسبة من السعر بعد الخصم ويُستحق يوم إصدار العرض.
- الباقي يُقسم بالتساوي على الأقساط (افتراضياً 20 قسط كل 3 شهور)، وأول قسط بعد دورة واحدة من تاريخ العرض.
- وديعة الصيانة نسبة من السعر بعد الخصم، **لا تُحصّل في أول 8 أقساط** وتُوزع على الباقي.
- سعر الجراج يحدده الأدمن ويُوزع على كل الأقساط.
- كسور التقريب تُضاف لآخر قسط ليكون الإجمالي مطابقاً تماماً.

كل الأرقام السابقة (8 أقساط، 20 قسط، كل 3 شهور، نسبة الصيانة...) قابلة للتعديل من الإعدادات.

## لوحة الأدمن

- **الشركات وهوياتها**: إضافة الشركات، اللوجو والألوان والخط، بيانات الشركة والموقّع عنها، وملاحظات عرض السعر.
- **لوحة المالك** (لمالك النظام فقط): العملاء، إنشاء حساب عميل وأدمن له، الإيقاف/التفعيل، والدخول على أي حساب.
- **المستخدمون**: إنشاء/إيقاف، الدور، صلاحية العروض/العقود، وحدود لكل موظف: أقصى خصم، أقل مقدم، أقصى مدة.
- **الوحدات**: تعديل أي بيانات (الشركة، المساحة، الغرف، السعر، سعر الجراج، الحالة متاحة/محجوزة/مباعة، صورة خاصة)، تسعير جماعي بسعر المتر، نقل وحدات لشركة، واستيراد/تصدير CSV لكل شركة. كود الوحدة لازم يكون مميز على مستوى السيستم كله.
- **النماذج**: رفع صورة المسقط لكل نموذج وعدد الغرف والحمامات — تنطبق على كل وحدات النموذج.
- **الإعدادات**: النسب الافتراضية والحدود، نظام الأقساط والصيانة والجراج (عامة لكل الشركات).
- **صيغة العقد**: الصيغة المبدئية هي عقد بيع الوحدة السكنية الخاص بالشركة (29 صفحة + 9 ملاحق) وكل خاناته الفاضية بتتملي تلقائياً: بيانات الطرفين، بيانات الوحدة، الثمن والمقدم والباقي والصيانة بالأرقام والحروف، جدول الأقساط (ملحق 1)، المخطط العام (ملحق 2) ومخطط الوحدة (ملحق 3)، التوقيعات والختم. صيغة عامة + صيغة خاصة لأي شركة. محرر للعقد مع إدراج البيانات (`{{client_name}}`، `{{installments_table}}`، `{{client_signature}}`...)، أو استيراد العقد من ملف Word.
